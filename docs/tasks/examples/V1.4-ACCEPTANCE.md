## Gate 函数定义

| Gate | 函数名 | 检查内容 | 适用 Action |
|------|--------|----------|-------------|
| G1 | `gate_task_file_exists` | TASK 文件存在（搜索 .ai/tasks/、docs/tasks/examples/） | 所有写 action |
| G2 | `gate_meta_format_valid` | 元信息格式合法（含 ## 0. 元信息 + Task ID + Status 非空） | 所有写 action |
| G3 | `gate_issue_bound` | GitHub Issue 已绑定（#N 格式，非"待创建"/空） | plan, dev, test, collect |
| G4 | `gate_branch_matches` | 当前 git 分支匹配 TASK 元信息中的 Branch | plan, dev, test, collect |
| G5 | `gate_plan_completed` | plan_result.md 存在 | approve-plan, dev |
| G6 | `gate_approval_valid` | approval.json 存在 + plan hash 匹配当前 plan | dev |

## 幂等性规则

| Action | 幂等行为 | --force 行为 |
|--------|---------|-------------|
| validate | 天然幂等（只读） | 同 |
| plan | plan_result.md 已存在 → warn + 拒绝 (exit 5) | 覆盖现有 plan |
| approve-plan | approval.json 存在 + hash 匹配 → warn "已审批" | 重写审批记录 |
| dev | dev.log 已存在 → warn + 拒绝 (exit 5) | 允许重新 dev（释放旧锁） |
| test | 允许重新测试（每次新增 test.log） | 同 |
| collect | result_bundle 已存在 → warn + 拒绝 (exit 5) | 覆盖现有 bundle |
| pause | 已 PAUSED → warn "已暂停" | 同 |
| resume | 未暂停 → warn "未暂停" | 同 |
| cancel | 已 CANCELLED → warn "已取消" | 同 |
| status | 天然幂等（只读） | 同 |

## 退出码约定

| 码 | 含义 | 使用场景 |
|----|------|----------|
| 0 | 成功 | Gate通过+脚本执行成功 |
| 1 | Gate/转换失败 | G1-G6任一不通过 或 非法状态转换 |
| 2 | 参数错误 | 缺少task_id或action参数 |
| 3 | 锁冲突 | 另一TASK持有锁 |
| 4 | 文件不存在 | TASK文件/产物文件不存在 |
| 5 | 幂等拒绝 | 重复操作且未传--force |
| 6 | 外部操作dry-run提示 | 仅打印拟执行命令（非错误） |
