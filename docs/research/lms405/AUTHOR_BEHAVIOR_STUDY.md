### 复算

在仓库根设置以下环境，选择一个新目录。冻结SH CSV及其Session证据来自既有统一MDS导出。报告可比较逐Bar、动作及前后腿；测试确认模式须通过显式开关开启。作者动作标签在回放后加入差异表。

```sh
export PYTHONDONTWRITEBYTECODE=1
export PYTHONPATH=.:services/quant-api:packages/quant-core:scripts/research
py=services/quant-api/.venv/bin/python
study_dir=$(mktemp -d /tmp/lms-author-study.XXXXXX)
ev=docs/research/lms405/evidence
market=output/lms-confirmed-samples-provenance-20261029

"$py" scripts/research/lms405_jm_may_case.py \
  --input output/lms405-jm2609-may-20261016/market-read-authorized/JM2609_2026-05-20_2026-05-22_1m.csv \
  --output "$study_dir/jm-prices.json"
"$py" scripts/research/lms_near405_author_study.py archive-review \
  --evidence "$ev" --jm-prices "$study_dir/jm-prices.json" \
  --sh-prices "$ev/sh2701-scoped-market-20261028.json" --output "$study_dir/cases.json"
for mode in AUTHOR INDEPENDENT
do
  "$py" scripts/research/lms_near405_author_study.py replay --mode "$mode" \
    --bars "$market/SH2701.csv" --provenance "$market/SH2701-provenance.json" \
    --input-sha256 4583c1d84f5739e9a750b286c59ecdd4d2a6925f9e5acc03904f64496f84bdb4 \
    --scenario "$ev/sh2701-author-study.json" --output "$study_dir/$mode"
done
"$py" -m pytest -q -p no:cacheprovider services/quant-api/tests/lms405
```

`--recovery TWO_CLOSES_BEYOND`启用解锁实验。要恢复人工路径，用`--checkpoint`提供上次检查点，并用`--decisions`追加确认记录。检查点绑定规则、已有区域和行情前缀。缺少覆盖、信号周期、初始状态或动作时间时，比较报告保留不可判定。
