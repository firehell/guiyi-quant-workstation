# 策略：MA 均线突破系统

## 策略简介

经典的均线突破策略，通过快慢双均线的金叉死叉信号捕捉中期趋势行情。

## 核心逻辑

- **金叉做多**：快线上穿慢线 → 开多仓
- **死叉做空**：快线下穿慢线 → 开空仓（或平多）
- **止损**：固定比例止损

## 适用品种

- 趋势性较强的期货品种
- 建议配合成交量过滤

## 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| fast_period | 5 | 快均线周期 |
| slow_period | 20 | 慢均线周期 |
| stop_loss | 0.03 | 止损比例（3%） |
