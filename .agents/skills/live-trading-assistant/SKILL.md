# Live Trading Assistant Skill

## 阶段边界

- V1：只做信号和研究，不下单。
- V1.5：接模拟账户，展示持仓/委托/成交。
- V2：实盘账户展示 + 风控拦截 + 人工确认下单。
- 暂不做无人值守自动交易。

## 订单流程

信号 -> 订单草稿 -> 风控检查 -> 展示风险信息 -> 用户人工确认 -> 发出委托 -> 记录委托/成交/撤单 -> 归档复盘。

## 必做安全

- 交易账号和密码只读环境变量或安全输入。
- 真实下单前必须二次确认。
- 所有订单必须先经过风控。
- 异常断线、行情中断、重复下单要拦截。

## 禁止

- 第一版接实盘自动下单。
- AI 自动决定下单。
- 保存明文交易密码。
- 没有风控的订单直达交易接口。
