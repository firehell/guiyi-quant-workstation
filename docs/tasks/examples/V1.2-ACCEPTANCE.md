  docs/tasks/examples/TASK-20260709-002-workstation-v1.2-github-issue-trace.md

# 3. 回填编号（替换 <N> 为上一步输出）

  docs/tasks/examples/TASK-20260709-002-workstation-v1.2-github-issue-trace.md

scripts/ai/update_issue_status.sh \
  TASK-20260709-002-workstation-v1.2-github-issue-trace PLAN_READY \
  docs/tasks/examples/TASK-20260709-002-workstation-v1.2-github-issue-trace.md

scripts/ai/comment_issue_result.sh \
  TASK-20260709-002-workstation-v1.2-github-issue-trace test \

  TASK-20260709-002-workstation-v1.2-github-issue-trace delivery \
