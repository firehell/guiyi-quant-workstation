# Risk Center Skill

## 未来研究边界

当前 v1.0.0 没有账户、持仓、订单、策略或回测子系统。本 Skill 只用于未来明确的新研究/风险计算合同，
不表示当前存在模拟或实盘能力，也不得创建订单执行路径。

## 候选风险规则

- 单笔亏损默认不超过账户权益 0.5% - 1%。
- 限制最大保证金占用。
- 限制最大同时持仓数。
- 达到最大连续亏损后降级或暂停策略。
- 回测和模拟达到最大回撤阈值后进入观察。

## 仓位公式

```text
单笔允许亏损金额 = 账户权益 * 单笔风险比例
每手风险 = abs(入场价 - 止损价) * 合约乘数
理论手数 = floor(单笔允许亏损金额 / 每手风险)
最终手数 = min(理论手数, 保证金允许手数, 最大手数限制)
```

## 输出

- 输入字段。
- 仓位计算。
- 保证金占用。
- 单笔、策略级、账户级风险限制。
- 回测统计方式。
- 研究观察的风险标记方式；不得扩展为订单拦截/执行系统。

## 禁止

- 不看止损距离直接开仓。
- 满仓多品种。
- 忽略保证金。
- 实盘绕过风控。
