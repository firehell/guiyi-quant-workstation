# Risk Center Skill

## V1 风控

- 单笔亏损默认不超过账户权益 0.5% - 1%。
- 限制最大保证金占用。
- 限制最大同时持仓数。
- 达到最大连续亏损后降级或暂停策略。
- 回测和模拟达到最大回撤阈值后进入观察。

## 仓位公式

```text
单笔允许亏损金额 = 账户权益 * 单笔风险比例
每手风险 = abs(入场价 - 止损价) * 合约乘数
理论手数 = floor(单笔允许亏损金额 / 每手风险)
最终手数 = min(理论手数, 保证金允许手数, 最大手数限制)
```

## 输出

- 输入字段。
- 仓位计算。
- 保证金占用。
- 单笔、策略级、账户级风险限制。
- 回测统计方式。
- 模拟/实盘拦截方式。

## 禁止

- 不看止损距离直接开仓。
- 满仓多品种。
- 忽略保证金。
- 实盘绕过风控。
