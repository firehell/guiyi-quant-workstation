# Backtest Report Skill

## 报告目标

报告必须帮助判断策略是否值得继续研究，而不是只展示收益曲线。

## 必须指标

- 总收益、年化收益、最大回撤。
- 胜率、盈亏比、期望值。
- 最大连续亏损、交易次数。
- 手续费总额、滑点估算。
- 收益回撤比、月度收益、品种贡献。
- 参数稳定性和样本外表现。

## 图表

- 资金曲线。
- 回撤曲线。
- 月度收益柱状图。
- 品种收益分布。
- 盈亏分布。
- 交易点 K 线图。

## 判断规则

- 不能只看收益。
- 必须解释最大回撤和连亏是否适合 10 万级别账户。
- 检查收益是否集中于少数品种或少数月份。
- 进入模拟盘前必须看样本外和执行成本。
