# 四位一体焦煤日线研究

结论：按 owner 确认的三组同日共振条件，2023-01-03 至 2026-10-22 的919个焦煤主力有效日均没有入场信号。无完整交易样本，胜率、盈亏比与胜率置信区间不可估计，不能写成胜率0%，也不能据此证明策略有效或无效。本轮未调参或放宽条件。

## 固定研究合同

输入来源为 owner 提供的《四位一体指标交易系统手册.docx》及聊天补充的风雷益、地山谦源码；后两者的计算公式固化在本次独立研究脚本中。源码优先于手册的文字释义。例如地天泰源码要求 `L=REFDATE(REF(LLV(L,100),3),DATE)`，不把它改成“跌破100日低点”；火天大有“卖空”只表示平多，不开空。

| 独立候选 | 同一完成日线的入场条件 |
| --- | --- |
| 趋势爆发 | 重仓买；风雷益上穿1.75；地山谦G2向上且无逃高点；无地天泰起爆点A |
| 底部潜伏 | 地天泰起爆点A与地山谦逃底点同时出现 |
| 回踩低吸 | 关注或买多；ZD1向上；风雷益在闭区间[1.75,2.00] |

“G2向上、当日无起爆点A、ZD1向上、[1.75,2.00]”是 owner 批准的研究定义，不是作者原文已量化条件。候选独立运行，每次一手、只做多、无加减仓。止损固定为信号日最低价减一个tick；首次卖空或逃高点全平，退出优先，同次不重新入场。

日线在权威Session结束后才可观察；最早严格晚于该观察时刻的可交易分钟开盘执行。初始止损遇开盘跳空直接按可执行开盘价退出；分钟内触及止损只在分钟完成后可知，再于严格更晚分钟开盘退出。连续分钟可能跳过与确认时间相同的下一开盘。这是保守的完成分钟执行模型，不是触价即时成交。采用历史适用开仓、平今或平昨手续费，单边0/1/2 tick滑点分别计算，主结果为1 tick；零成交量、涨跌停及越界滑点价格不得生成成交。

## 公式与重绘边界

复用现有 `htdy_original.xma` 的居中截断均值实现；每个物理合约从权威生命周期日线预热，逐日前缀重算，只冻结末端当时信号。对同一前缀内的前一日指标，使用当时该前缀所见值；不得用以后重绘的最终图反写历史决定。新主力切换使用新物理合约自身前缀，不继承旧约状态。

- `CAPITAL=0`：使用期货分支；`CURRBARSCOUNT=1` 只在当前前缀末端成立。`FROMOPEN` 仅影响未被信号消费的V5/V10/V20链，明确省略。
- EMA/SMA由首个有限值播种，REF缺失前值为非有限值；除零为缺失，禁止填0。FILTER保留首次真值并抑制随后N根。统一至少103根同合约预热，并验证相关值有限。
- [通达信官方函数列表](https://help.tdx.com.cn/gspt/docs/markdown/redword/functionlist.html)明确XMA使用未来数据、REFDATE引用指定日期的值。本研究对唯一日线日期采用逐日日期查找，即 `REFDATE(DJ,DATE)=DJ`；变化DATE参数的原软件逐值行为没有oracle验证，整体保留 `original_software_parity=NOT_PROVEN`。
- 既有XMA(6)偶数窗口归一到7的规则仍为 `externally_unresolved`。“关注”分支依赖它，因此回踩候选正式ready被阻断；另行开放约定诊断计算，标记 `CONVENTION_ONLY_XMA6_UNVERIFIED`。诊断计算也没有入场，不把阻断冒充零信号。

919日当时输入均通过本候选自身预热与有限值检查。最终历史图对照中，907日ZD1数值不同，247日ZD1向上状态不同；买多45日、卖空29日、关注10日、重仓买1日、合并退出28日不同。两种视角的三组入场均为零，仍不能混用历史图与当时信号。
