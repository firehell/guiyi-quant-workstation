## ADDED Requirements

### Requirement: W01 页面与配置

系统 SHALL 满足以下约束。桌面 Web 分列实时行情、最近一次成功发布的牛哇盘后参考/历史回测，以及快期火天大有和苏冰独立量化的账户事实。展示行情时间、牛哇数据截至交易日与计算完成时间、run 身份及更新状态。主图观察层只读，独立入口按现有合同。

#### Scenario: 只读页面及缺数

- **GIVEN** 没有成功 run、任务失败或有既有成功 run
- **WHEN** 打开主图/首页、切周期、分页
- **THEN** 分别显示暂无、旧结果及错误、或指定版本的结果；不会启动引擎或登录柜台，不拼接零成本旧收益。

#### Scenario: 新交易日盘中

- **WHEN** 行情推进而当日盘后结果尚未发布
- **THEN** 报价时间继续前进，牛哇图层停在上次成功截至日，历史动作落在原 bar；不把旧动作标成盘中新信号，不补算、不产生账户意图。首次无结果、处理中与失败沿用各自状态。

#### Scenario: 独立入口回归

- **GIVEN** 打开独立快期、苏冰及既有消息定位
- **WHEN** 灰度切换牛哇显示
- **THEN** 既有账户来源、定位和快照可核对；观察图层不写 Event，不触发真实通知。
