# 完整策略剩余规则

本表是缺口清单，不补造作者公式；本地行情不能证明作者私有决策。

| 项目 | 作者已知约束 | 当前能力 / 缺的定义 | 本地验证与依赖 / 验收 |
|---|---|---|---|
| 首次入场 | 方向与关键节点有关 | 显式初始单位前像；缺入场触发、失效、优先级 | 先人工输入方向/区域/允许时段，独立候选合同后可验证因果行为 |
| 退出 | 有保护和解锁线索 | LOCK/UNLOCK不等于退出；缺全清触发 | 与首次入场合同一起定义；不得默认为止盈倍数 |
| 失败回补 | 未充分识别 | 无自动回补；缺失败定义与次数 | 依赖入退场，验收禁止循环重复动作 |
| 抓M | 私有分类未识别 | 不反手、不抓M | 先作者定义证据，行情只能检验候选 |
| L/M/S环境 | 概念公开，精确阈值未知 | 无环境自动Gate | 独立版本及逐值样本后再接入 |
| 区域生成/更新/失效 | 日更点位可观察 | 外部显式区域；自动算法未知 | 先已知时点与区域生命周期合同 |
| 结构自动选点 | 九组解释非信号 | 无自动选点 | 先标注独立样本，定义相等与替换边界 |
| ebar/tbar | 定义不足 | 未实现 | 先最低可确定规则与反例，不能造常量UNKNOWN计算器 |
| 周期切换 | 可降周期，阈值未知 | 固定completed 5m | 需切换触发与双周期时间合同 |
| 仓位 | 单位研究不等于真实手数 | 显式双腿；缺资金/风险模型 | 策略合同之后独立版本及风险验收 |
| 成本/执行 | 原版未知 | fill/performance=null | 物理合约、下一可执行时刻、费滑限价换月合同后验证 |
| OOS | 当前样本已见 | 仅开发/跨样本检查 | 冻结完整候选后另取未见样本与Walk-forward |

唯一优先下一项：首次入场与退出的独立候选合同。人工必须提供初始方向、区域及其当时已知时间、允许研究情景；可基于现有 ibar/pinbar 提出明示近似候选，但不默认接入确认回放或正式策略。
