## 阅读状态与日期

- `ENTRY_LINK_VERIFIED`：发布入口已定位，正文是另一条记录。
- `ARTICLE_TEXT_READ` / `DETAIL_TEXT_READ_TO_END`：文章正文已读到结尾；是否有图及图片核验情况见正文。
- 含 `KEY_IMAGES_READ` / `HOLDINGS_IMAGE_READ` / `POSITION_IMAGE_READ`：已看关键持仓图，不能推导所有装饰图和软件字段全部核验。
- 含 `IMAGES_PENDING` / `IMAGE_PENDING` / `IMAGE_AUDIT_PENDING`：图片未完成，保留正文摘要及续接点。
- 含 `TEXT_PARTIAL`：长文可能尚需点击展开；不能称全文已读。
- `PARTIAL`：已做部分定向阅读；`NOT_STARTED`：尚未检查，零条不表示没有发布。当前没有任何日期标记为全量完成。

`published_at` 来自详情页面，`title_date` 另存文章标题日期，`observed_at` 是本次读取时间。日期采用北京时间；夜盘不自动移动到另一个交易日。未单独证明的交易日归属保持未知。`edited` 为当前可见标记，未见标记不等于从未编辑；旧文当前内容不能自动认定为事前不可变发布。

## 检索记录、限制和跳过原因

本批使用作者主页倒序、日期词 `2026.10.27` / `2026.10.26`、系统词 `4.0.5`、品种词“纸浆”、文章推荐阅读、已发现详情链接和正文引用。其他品种记录主要通过主页与引用定位，不能虚报所有品种关键词均已搜索。

日期词搜索曾显示“暂无内容”或“没有更多内容”，但只返回已知的两条汇总日志，漏掉同日已确认文章与系统帖。因此搜索结果耗尽不作为当日全量完成证明。主页加载可能重排和重复，向下滚动到26日也不足以证明27日无遗漏。长文展开和图片懒加载分别记录，不能把当前可见摘要当全文。

正常登录网页可见部分标注V+的全文，本批只阅读当前账户已经正常可见内容，没有购买、绕过访问限制或私信。遇到剪贴板冲突提示后先读取地址栏核对意图，再继续；图片元素失效时刷新可见状态取得新索引，不将失败操作算读取成功。

明确跳过的例子（不加入三类正文索引）：27日[14:52足球评论](https://weibo.com/1885745060/RoBCfblGh)、[15:16游戏闲聊](https://weibo.com/1885745060/RoBMftUwE)、[15:21足球转评](https://weibo.com/1885745060/RoBO3jv5B)。其他重复旧理论转发、表情图、没有新增节点的新闻评论优先略过。27日15:26上证评论已留简短来源以说明当日上下文，之后同类无新增信息评论不继续扩展。
