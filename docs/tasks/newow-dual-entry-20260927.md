# 双策略融合入口与后续功能设计

## 目标与本版范围

详情页第三个分析选项由“主升浪”改为“双策略”。主升浪内核、API 和直接路由保留；融合不是第四个策略公式。
双策略主图使用趋势黄蓝带与震荡 HHV/LLV 的独立双轨，统计使用独立融合模型，不把两策略收益相加。
本版接入现有融合 API 和面板：自动读取趋势／震荡／融合三组全窗口统计，直接展示融合交易及每笔建仓、清仓来源。

## 融合规则与牛哇差异

1. 同一权威输入、completed Bar、cutoff 下重放趋势和震荡。
2. 每根先 CLEAR，再 BUILD。持有时任一策略 CLEAR 可退出；空仓时任一策略 BUILD 可进入。同根可先清后建。
3. 同方向信号优先震荡参考价，其次趋势参考价；允许跨来源配对，持有期间不重复建仓。
4. 同一物理合约及有效数据段内配对；换月／数据中断单列，不计入 CLOSED 累计。
5. Decimal 零费用、零滑点；仅窗口内建仓且已清仓的收益简单相加。期初已有、未清仓浮动独立展示。
6. 牛哇普通融合末尾强制按末根 close 结算；项目合同保留 OPEN。本版不改变该口径。
7. 图上双轨收益、主导切换提示不参与融合交易状态机，不等于融合收益。

## 页面、加载和交互

- 路由 `view=newow&strategy=trend&newow_mode=dual`：展示身份独立，API 内核身份仍为趋势和震荡。
- 第三个 tab 进入双策略，保留品种、周期、报价与页面布局，不整页刷新。退出双策略恢复单策略面板。
- 主图自动读取同窗口、同物理输入的伙伴策略。主图顶部明确“趋势侧策略概览”，目标／吸筹与综合决策仍为趋势侧事实，不伪称融合目标。
- 下方不显示趋势收益面板冒充融合；自动读取三组统计及融合记录。失败清除旧结果，允许重试；切换品种、周期、cutoff、统计窗口时取消旧请求，迟到结果不得覆盖新身份。
- 当前统计沿用已接受的参考统计窗口。融合 API 返回完整窗口统计、最多最近 200 条记录，截断必须明确显示，不能从这 200 条重算全历史收益。
- 保留原单策略“双策略对照”工具；它只控制图形叠加，语义与“双策略”入口分开。
