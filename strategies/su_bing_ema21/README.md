# 策略：苏冰 EMA21 趋势跟踪

## 策略简介

基于 EMA21（21 周期指数移动平均线）的趋势跟踪策略，通过价格与 EMA21 的相对位置判断趋势方向，在趋势确立时入场，在趋势反转时离场。

## 核心逻辑

- **做多信号**：价格上穿 EMA21 且收盘价 > EMA21
- **做空信号**：价格下穿 EMA21 且收盘价 < EMA21
- **平仓条件**：持仓方向的反向信号触发

## 适用品种

- 股指期货（IF / IC / IH）
- 商品期货趋势行情（螺纹钢 rb、铜 cu）

## 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| ema_period | 21 | EMA 周期 |
| stop_loss | 0.02 | 止损比例（2%） |
| position_ratio | 0.1 | 单次开仓比例 |
