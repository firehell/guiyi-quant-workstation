# 归一量化前端开发 Skill

## 技术栈

- Vue 3
- Vite
- TypeScript
- Naive UI
- Pinia
- Vue Router
- Axios
- Lightweight Charts
- ECharts

## 页面模块

V1 优先：
1. 首页 Dashboard
2. 数据中心
3. 合约 / 品种池管理
4. K线工作台
5. 策略中心
6. 回测任务
7. 回测报告
8. 信号扫描
9. 复盘中心
10. 系统设置

## 规则

1. 不使用 Next.js。
2. 不做登录和多用户权限。
3. 先使用 mock 数据。
4. 前端不直接连接数据库。
5. 所有数据通过 FastAPI。
6. 每次修改后给出运行命令和测试方法。
