## Post-Auth：一键 E2E（推荐）

在 **Mac mini 本地终端**（非 Agent 环境）完成登录后，在仓库根目录执行：

```bash
gh auth login
# 选择：GitHub.com → HTTPS → Login with a web browser

gh auth status
gh repo view --json nameWithOwner,url

# 一键跑通 labels + Issue 创建 + 回填 + plan/test/execution/delivery 评论 + label 同步
scripts/ai/run_v12_post_auth_e2e.sh
```

成功后记录脚本输出的 `ISSUE_URL`，人工检查 Issue 页面，再更新本文件验收表 3–8 项为 **通过**。

若 labels 已创建、Issue 已存在，可：

```bash
scripts/ai/run_v12_post_auth_e2e.sh --skip-labels --skip-create
```
