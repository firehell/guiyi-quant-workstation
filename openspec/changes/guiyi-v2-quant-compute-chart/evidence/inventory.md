# 指标与显示迁移盘点

| 分类 | 能力 | 归属和使用边界 |
|---|---|---|
| 通用指标 | EMA10/21/60、MACD、ATR、STDDEV、BOLL、HHV/LLV、OBV、量比 | Quant Core 白名单。TA-Lib 返回原始分析数值，量比用已完成 Bar 的前 N 根均量。Free、HTDY、苏冰的选中 EMA 与 Free 的可选 BOLL 通过有界 Market 图表读取；牛哇 MACD 用同 owner 回放前缀。 |
| 自主特征 | 趋势方向、EMA21 斜率、OLS5、ATR 归一化；Swing Pivot、支阻、突破与回踩 | 计算注册表复用基础节点。形态发生、确认和可知时间分别保存；回看标记的视觉位置不授予策略权限。 |
| 牛哇主图 | 黄蓝趋势带、左右趋势通道、震荡/Donchian/动态箱体、主升浪、杯柄、突破、影线、D1–D6、九转、高低点、攻击线、目标/吸筹、双策略背景 | 继续由各牛哇产品结果/Primitive 负责原身份和布局。动作、Hint、止盈/止损说明及结构辅助保留现有开关；纯呈现从已保存结果取得。 |
| 牛哇副图 | 主力控盘、涨跌动能、照妖镜、趋势转折及研究 MACD | 四种原公式注册为专属结果，MACD 为单独通用指标适配。原默认布局仅占一个选中副图。照妖镜保持重绘回看和不可用于历史动作。 |
| HTDY 与苏冰 | HTDY 原始和严格研究、苏冰同花顺 15m 状态及原专属趋势/量价、独立同花顺 MACD + MA21 观察 | 计算、研究结果和历史 Alert 保留原版本。Web 同花顺 MACD 的首值种子、柱体倍数和 ▲/▼ 观察是独立显示合同。 |
| Range Detector | Lux Range 支撑/阻力箱体，与苏冰动态区间的独立身份 | 继续使用现有只读区间探测合同。图中回画至区域起点不改变确认时间。 |
| 显示变换 | 通用黄色成交量、苏冰 2x/3x、牛哇成交量和实验量能 | Quant Chart 保留相同物理段、确认状态、窗口、分值和 Session 限制。颜色和量能档位只进入图层。 |
| 业务原件 | BUILD/CLEAR、Hint、Alert、参考交易、模拟委托和成交 | 由既有业务响应携带来源。Chart 只渲染，不从显示行情重建或采纳新的业务事实。 |
| 既有研究统计 | 首页与品种研究的 `physical_owner_quality_v5` 日周趋势及 ATR 分位 | 保留已版本化的统计口径。旧 EMA/MACD/ATR 的通用注册已退役；专属/历史公式保留各自计算入口。 |

真实冻结样本和性能结果见 [performance.json](performance.json)。冻结脚本只读 MarketDataService，输出文件放在隔离目录。性能矩阵以 2026-11-25 为截止，缺少严格覆盖的组合不补造历史。图表和计算模式联调依赖见 [任务表](../tasks.md)。
