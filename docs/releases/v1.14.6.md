# v1.14.6 牛哇页面与策略消息

本次整理已合入 develop 的功能，发布源码版本；正式运行服务继续使用 v1.14.5。

- 消息页面采用紧凑列表，展示牛哇三种主策略及独立双策略在周线、日线、60分钟产生的已保存信号，支持筛选与跳转到对应图表。只展示真实持续记录，不用历史 seed 冒充新消息。
- 整理牛哇综合决策折叠、依据展开、多周期嵌套波段路径、分析弹窗比例和参考收益曲线；修复已保存参考记录的理论值计算。
- 增加震荡攻击线及独立 J 辅助提示；策略副图默认主力照妖镜，移除策略场景的 MACD 入口。
- 纳入 5m/15m/30m 趋势、震荡及独立双策略持续记录代码，目标容量1260路、360调度key；新增540路尚未在生产构建或启用，短分钟主升浪保持关闭。
- 修复消息页提交误带入的不完整首页卡片入口：恢复完整旧首页，并保留消息跳转；未纳入工作区尚未提交的首页卡片和研究文档。
