# 策略：N 结构价格形态识别

## 策略简介

基于价格结构（N 型形态）的形态识别策略，通过识别价格的 N 字形上升/下降结构来判断趋势延续信号。

## N 结构定义

- **上升 N 结构**：高点 → 回撤 → 突破前高 → 做多
- **下降 N 结构**：低点 → 反弹 → 跌破前低 → 做空

## 适用场景

- 趋势行情中的回调做多机会
- 适合配合更大级别趋势过滤

## 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| lookback | 20 | 形态识别回溯周期 |
| breakout_threshold | 0.001 | 突破确认阈值 |
| stop_loss | 0.02 | 止损比例 |
