## 4. v3.3.79 新增规则的原式补充

**XP1**：`trend.week=up && trend.day=down` 输出周期冲突，独立于 MM/R、确定性评分。原站文件新增这个出口，内部 VERSION 没更新；归一数值匹配不能掩盖字段缺失。

**综合卡动作表**：原始 `holding/cleared/其他` 归一为上/下/中性。方向周期D、执行周期X：D中性→等待；下/下→空仓；下/上→减仓；下/中性→空仓；上/下→等待并标冲突；上/中性→等待；上/上→建仓。周basis为周/日，日basis为日/60m。这是页面动作文案与强度/冲突合同，未经版本设计不得替换当前策略信号。

**震荡实验1–4**：基础买入仍触LLV10；测试1加7%硬止损，测试2另固定入场HHV目标，测试3另加MA10上升的入场门槛，测试4改卖出信号K线确认制及12%硬止损。实验分支 `_soldThisBar` 与普通分支不同；不能只换策略名称就复用普通结果。本轮记录四组公开摘要，不声称归一实现或盈利有效。
