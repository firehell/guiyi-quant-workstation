## Context

交易案例由用户归集。模拟中心、苏冰 PortfolioJournal、牛哇参考交易和回测 Run 保持各自的证据所有权。

## Decisions

- PostgreSQL 持久化计划及版本、案例、事件、日周复盘和幂等写入记录。案例锁定计划版本。版本检查与写入同事务提交。
- 时间线保存发生时刻与记录时刻。来源交易日优先；人工记录由用户确认交易日。周锚点为交易日所在周的星期一。
- 执行来源按账户和原生成交身份校验。归案按案例加行锁，以唯一索引约束全局重复关联，撤销保留审计记录。研究对照单独保存关联。
- 所有证据通过拥有方只读接口验证及读取。数据库仅持久化引用和排序所需的时间身份。单个来源不可读时继续提供其余案例内容。
- 发布沿用工作站组件版本线。组件的准确源码通过 tag 锁定，生产迁移与应用部署随工作站版本进行。
