# WorkBuddy Bug 修复提示模板

## 使用方式

遇到 Bug 时，按此模板向 WorkBuddy 描述问题，触发 ui-bugfix 或相关技能包。

---

## Bug 报告模板

```markdown
## Bug 报告

**Bug 标题**：[一句话描述 Bug]

**严重程度**：
- [ ] P0 — 功能完全不可用，阻塞主流程
- [ ] P1 — 功能部分异常，有临时绕过方案
- [ ] P2 — 界面问题或轻微逻辑错误

**复现步骤**：
1. 进入 [页面/功能]
2. 执行 [操作]
3. 观察到 [异常现象]

**期望行为**：
[描述应该发生什么]

**实际行为**：
[描述实际发生了什么]

**错误信息**：
```
[粘贴错误堆栈或控制台输出]
```

**环境信息**：
- 前端版本：
- 后端版本：
- 浏览器：
- 操作系统：

**相关文件**（如果知道）：
- [文件路径]

**截图**：
[如有，放入 screenshots/ 目录并在此引用]
```

---

## 修复验证检查清单

修复完成后，确认：
- [ ] 原 Bug 复现路径不再出现该问题
- [ ] 相关功能没有回归问题
- [ ] 错误处理是否完善
- [ ] 日志是否正确记录
- [ ] 如涉及资金计算，验证精度是否正确

---

## 常见 Bug 分类

| 类型 | 对应技能 | 关键词 |
|---|---|---|
| 前端显示异常 | ui-bugfix | 样式/渲染/图表 |
| API 报错 | quant-backend | 500/404/鉴权 |
| 数据异常 | futures-data | 数据缺失/格式错误 |
| 回测结果错误 | backtest-engine | 指标计算/净值曲线 |
| 策略信号异常 | futures-strategy | 信号/持仓/止损 |
