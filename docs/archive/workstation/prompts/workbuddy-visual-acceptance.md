# WorkBuddy Visual Acceptance Prompt

Use this prompt after visual inspection.

Return:

```text
Issue:
TASK:
PR:
page:
viewport:
result: PASS | FAIL | NOT_VERIFIED
blocking:
non_blocking:
evidence:
tests:
risks:
next_action:
```

Do not declare PASS if screenshots, browser state, console, or network evidence were not checked.
