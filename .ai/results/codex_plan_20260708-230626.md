### 当前理解

本轮是 WeChat / 企业微信 AI workflow 的只读 Plan 烟测；项目边界仍是本地运行的国内期货量化研究、数据、回测、信号提醒、复盘和人工观察工作站。V1 不做 SaaS、不做自动交易、不做无人值守下单，信号扫描只提醒，不直接变成实盘指令。

### 计划摘要

1. WorkBuddy：负责需求整理、任务拆解、QA 清单、交付报告和可见 UI 问题整理，不直接改业务逻辑、数据链路、策略、回测、数据库。
2. CodeBuddy：作为企业微信 / 本地远程入口，先报告 `pwd`、git root、branch/status，读取仓库文件，调用受控脚本。
3. Codex：通过 `scripts/ai/codex_plan.sh` 做第一轮只读 Plan；用户明确确认后，才可通过 `scripts/ai/codex_dev.sh <task_file> codex/<task>` 或 `feature/<task>` 进入开发。
4. Read-only Plan gate：第一轮只允许检查、分析、输出计划，不得修改仓库文件。
5. User-confirmation gate：开发不能从模糊指令、后台任务或“已开始”状态推断授权，必须等待用户明确确认。
6. 禁止动作：自动交易、自动下单、自动 push/merge/release/deploy/PR、打印或写入 webhook/token/license/账号凭证、修改 `.env`、删除或改写可信历史数据、把 `validation` / `legacy_reference` / `candidate` / `failed` 数据提升为 active input、运行真实企业微信通知 smoke，或使用 `codex exec --sandbox danger-full-access`。
