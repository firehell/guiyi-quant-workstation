# 牛哇日周状态摘要 · 2026-09-27

用户目标：研究牛哇综合决策下方的状态卡、多种股票状态和交互，在归一综合决策下方实现；当前只做日线／周线。

## 来源与边界

公开源页：<https://www.v8848.cn/stock_detail.html?code=688122.SH>，详情页标识 v3.3.59。本次读取 HTML SHA-256：`b12da74d89a7ac304d7479999d11f13ab53ced834a8472f937d78a0c1bd03709`。原始页及接口响应留在本地临时目录，未纳入仓库分发。

已核对源码的趋势16格名称／风险、展开与折叠、风险颜色、价格方向与百分比、建议仓位绑定综合决策、看空文字保护；震荡的多周期状态详情和三周期27格矩阵。公开 batch 接口读回9只股票，其中西部超导为周持有／日持有，江海股份为周空仓／日空仓，盛科通信为周空仓／日持有，覆盖上涨趋势、震荡下跌、筑底反弹的实际输入差异。该接口读回证明输入，不冒充多股票现场视觉验收。

现有 CDV2 是唯一输入；不新增后端策略计算、行情入口或模型请求。状态名称与价格位置为确定性页面解释。价格公式、16格表与日周震荡适配见[复刻手册](../research/newow-v3.2.82/REPLICATION_MANUAL.md)。60m、不公开的震荡底部确认、主力诊断和价格触发的 UI 状态覆盖不纳入本次实现。

## 实现

- `NewowDecisionV2Panel.vue`：按产品／策略／周期／as_of／snapshot_token 自动读取已有综合解释；同快照分页不重复请求；切换丢弃旧结果与请求，计算忙时安全提示。综合依据折叠，摘要放在其下方。
- `NewowStatusCard.vue`：左侧风险色条、周日标签、风险和参考仓位、说明、进度轨道、百分比、独立解读／多周期展开、折叠偏好、缺失／错误／重试，以及窄屏和键盘交互。
- `newowStatusCardPresentation.ts`：趋势16格和显式震荡日周9格；缺状态、缺 owner Segment 或合约冲突不推测。价格运算用有界十进制字符串和 BigInt，只有视觉进度截断。

不改变策略公式版本、ReferenceTrade、成本、账户或 Runtime。实现后的 commit/push 仅为 develop 集成。
