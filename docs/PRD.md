# 归一量化 PRD

> 全局总控：`docs/归一量化_Codex从零搭建总控文档_V1.md`
> 当前阶段：V0 命令行原型 + V1 Web 研究闭环

## 项目定位

归一量化是本地运行的国内期货量化研究与交易辅助系统。

第一阶段只做：

- 数据下载与清洗。
- K线查看与指标叠加。
- 策略配置与版本管理。
- 回测任务与回测报告。
- 交易明细与 K线买卖点标记。
- 信号扫描。
- 单笔复盘。
- 风控统计。

第一阶段不做：

- 全自动实盘。
- tick 级高频回测。
- 复杂盘口队列撮合。
- 多用户系统。
- 云端 SaaS。
- 手机 App。
- Web 策略代码编辑器。
- AI 自动生成策略并直接上线。

## V1 核心闭环

```text
数据下载
→ 数据清洗
→ 本地标准化数据仓
→ Web 查看 K 线
→ 选择策略和参数
→ 发起回测
→ 查看回测报告
→ K线上标记买卖点
→ 保存策略版本
→ 生成信号
→ 单笔复盘
```

## 数据源策略

TqSdk / 天勤专业版是项目核心目标数据源。当前实现应先用 sample/mock 数据跑通本地闭环，再通过统一适配器接入 TqSdk、RQData、Tushare 或 AKShare 等外部数据源。

系统必须采用统一数据层设计：外部数据源只影响采集适配层，回测、K线工作台、信号扫描和复盘默认读取本地标准化后的 PostgreSQL / Parquet / DuckDB 数据仓。

`tqsdk-python/` 是本地天勤源码参考目录，用于配合 TqSdk skill 查阅函数、对象和示例，不作为归一量化项目代码提交。

## 阶段规划

| 阶段 | 目标 | 第一版关系 |
|---|---|---|
| V0 | 命令行验证数据、Parquet、DuckDB、策略、回测 JSON | 当前必做 |
| V1 | Web 研究闭环，覆盖 K线、策略、回测、报告、信号、复盘 | 当前必做 |
| V1.5 | 模拟账户、企业微信提醒、人工确认 | 后续扩展 |
| V2 | 小资金半自动实盘辅助、风控拦截 | 后续扩展 |
| V3 | AI 总结、归因、策略迭代辅助 | 后续扩展 |

## 验收标准

- 前端能访问 FastAPI，并展示数据、策略、回测、信号、复盘核心页面。
- 后端能记录数据任务、合约元数据、策略版本、回测任务、信号和复盘结果。
- 历史 K 线能落到 Parquet，并能通过 DuckDB 查询给回测和页面使用。
- 回测必须包含手续费、滑点、保证金、最大回撤、连续亏损和交易明细。
- 策略信号和回测结果必须避免未来函数、数据泄露和过拟合。
- 所有账号、密码、license、token 只从本地环境变量读取，不写入代码库。
