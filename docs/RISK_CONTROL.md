# RISK_CONTROL.md — 风控系统设计

> 版本：v0.1 · 状态：草稿 · 更新日期：2026-06-22

---

## 1. 风控层级

```
账户级风控（最高优先级）
    └── 最大回撤熔断：> 15% 停止所有策略
    └── 单日最大亏损：> 5% 当日停止交易

策略级风控
    └── 单策略最大仓位：不超过总资金 20%
    └── 单策略单日亏损：> 3% 暂停该策略

订单级风控
    └── 单笔订单资金上限
    └── 重复下单检测（幂等性）
    └── 价格偏离度检查（防止异常价格）
```

---

## 2. 风控参数（从 .env 读取）

| 参数 | 环境变量 | 默认值 | 说明 |
|---|---|---|---|
| 单品种仓位上限 | RISK_MAX_POSITION_RATIO | 0.2 | 单品种不超过总资金 20% |
| 单日最大亏损 | RISK_MAX_DAILY_LOSS | 0.05 | 超过 5% 触发熔断 |
| 最大回撤 | RISK_MAX_DRAWDOWN | 0.15 | 超过 15% 停止所有策略 |
| 单笔止损 | RISK_STOP_LOSS_RATIO | 0.02 | 单笔交易亏损不超过 2% |

## 3. 熔断机制

```python
class CircuitBreaker:
    """
    熔断器：触发条件 → 停止交易 → 发送告警 → 等待人工确认
    """
    triggers = [
        DailyLossBreaker(threshold=0.05),
        MaxDrawdownBreaker(threshold=0.15),
        ConnectionLostBreaker(timeout=30),  # 行情断连 30s
    ]
```

---

## 4. 风控日志规范

所有触发风控的事件必须记录：
- 触发时间（精确到毫秒）
- 触发原因（哪个规则）
- 当时的账户状态（总资产、持仓、盈亏）
- 采取的动作（停止策略/平仓/告警）

---

## 5. 风控检查流程图

```
策略信号
    ↓
仓位检查 → 超限 → 拒绝下单 + 记录日志
    ↓ 通过
资金检查 → 不足 → 拒绝下单 + 记录日志
    ↓ 通过
日损检查 → 超限 → 熔断 + 告警
    ↓ 通过
下单执行
```
