# 归一量化 PRD

> 版本：V1 重构版  
> 当前阶段：V0 命令行原型 + V1 Web 研究闭环  
> 当前路线：米筐 RQData + vn.py 回测底座 + 自定义 Vue Web  
> 阶段边界：V1 不做自动实盘，不做 tick 高频回测，不做云端 SaaS。

---

## 1. 项目定位

归一量化是本地运行的国内期货量化研究与交易辅助系统。

项目目标不是做公开平台，而是服务用户本人及小范围朋友，把主观交易经验逐步转成：

```text
可配置策略
→ 可回测结果
→ 可复盘交易
→ 可扫描信号
→ 可验证执行
→ 后期可半自动辅助
```

当前用户约束：

| 项目 | 说明 |
|---|---|
| 市场 | 国内期货 |
| 优先品种 | 黑色、化工、能源 |
| 风格 | 趋势 / 波段 |
| 账户规模 | 10 万级别中小资金 |
| 第一阶段重点 | 研究、回测、复盘、信号扫描 |
| 第一阶段不做 | 自动实盘、tick 高频、复杂盘口撮合 |

## 4. V1 数据源策略

### 4.1 主数据源

V1 主数据源为：

```text
米筐 RQData
```

米筐负责：

- 历史分钟数据。
- 合约基础信息。
- 主力映射。
- 复权因子。
- 交易参数。
- 手续费、保证金、合约乘数等回测基础数据。
- V1 信号扫描的最新分钟级数据基础。

### 4.2 本地数据仓

正式研究数据必须进入本地数据仓：

```text
raw parquet
→ standard parquet
→ market_data_files
→ data_quality_reports
→ DuckDB / MarketDataReader
```

禁止回测和 Web 直接调用外部 SDK。

### 4.3 旧数据处理

| 数据 | V1 处理方式 |
|---|---|
| 早期米筐数据 | 清洗后可并入 standard parquet |
| 天勤旧数据 | validation source，只做交叉校验 |
| 交易练习者数据 | legacy_reference，只做页面测试和对照 |
| TuShare | V1 移除，后期辅助候选 |
| TqSdk / 天勤专业版 | V2 模拟 / 半自动实盘候选 |

正式回测默认只使用：

```text
data_role = primary
quality_status != failed
```

## 5. V1 回测策略

V1 不从零自研完整撮合引擎。

V1 回测底座采用：

```text
vn.py / VeighNa CTA BacktestingEngine
```

归一量化负责：

1. 回测任务创建。
2. 回测参数配置。
3. 策略版本绑定。
4. 调用 vn.py adapter。
5. 回测结果转换。
6. 报告入库。
7. K线买卖点复盘。
8. 风控统计。
9. Web 展示。

vn.py 负责：

1. CTA 策略模板。
2. bar 级回测。
3. 委托、成交、持仓等底层模拟。
4. 后期 CTP Gateway 候选。

## 10. 验收标准

V1 研究闭环完成标准：

```text
[ ] RQData 数据能下载
[ ] 数据能写入 raw parquet
[ ] 数据能标准化为 standard parquet
[ ] market_data_files 有文件索引
[ ] data_quality_reports 有质量报告
[ ] DuckDB 能查询 K线
[ ] Web 能展示 K线
[ ] 策略中心能展示策略和参数
[ ] 能创建回测任务
[ ] RQ Worker 能调用 vn.py 回测
[ ] 回测结果能转统一 JSON
[ ] 回测报告能入 PostgreSQL
[ ] Web 能展示资金曲线和回撤曲线
[ ] 交易明细能映射到 K线买卖点
[ ] 能生成信号扫描结果
[ ] 能做单笔复盘
```

安全验收：

```text
[ ] 没有账号密码入库或入代码
[ ] 没有自动实盘逻辑
[ ] 没有未来函数
[ ] 没有数据泄露
[ ] 回测包含手续费和滑点
[ ] 回测包含最大回撤和连续亏损
[ ] 回测结果明确不等于实盘结果
```

## 12. 实盘边界

V1 不做实盘。

V1.5 可做：

```text
信号扫描
→ 人工观察
→ 手动下单
→ 手工录入实际成交
→ 理论成交 vs 实际成交对比
```

V2 再评估：

```text
vn.py CTP Gateway
天勤 TqSdk
继续人工确认下单
```

即使进入 V2，也必须保持：

```text
信号
→ 风控检查
→ 人工确认
→ 发单
→ 成交回报
→ 日志归档
```

不得在未模拟和小资金验证前做无人值守自动实盘。
