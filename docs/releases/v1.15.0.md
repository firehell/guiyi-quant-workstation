## 运行边界

本版本包含原720路forward身份的受控升级：保留旧记录并停用旧身份，
同一事务建立60品种×4策略×3周期的新身份。新版参考状态从flat开始，
不继承旧OPEN参考交易；后续进度仅来自切换后的自然completed observation。
其余540路短分钟历史身份保持disabled，不扩大通知对象、Scope或交易阶段。

普通切换器仍拒绝新旧公式/profile/reference合同混用；本次专用控制器必须先
验证720路双射、源身份、整组事务回滚、现役锁和新旧记录读回，再切换全部正式服务。
保留旧观察记录、发送事实与unknown journal，不清空或改写旧stream来消除冲突。

发布、运行切换与自然业务验收分别记录。工程测试和固定历史资产不证明
Runtime Ready；自然盘中连续性仍须交易时段的真实证据。
