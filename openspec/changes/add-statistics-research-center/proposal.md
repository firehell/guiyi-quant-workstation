# 统计与 AI 研究中心

## Why

工作站能回答“这次回测如何”和“这笔交易如何执行”，但比较同一策略在不同品种、时段和市场状态的表现，仍需临时拼接样本。研究者还需要区分账户收益、单笔结果与信号后的价格变化，并能从结论回查当时可知的数据。

## What Changes

新增一个只读消费业务事实的研究领域。首期用可复算的数据集把账户日收益、交易案例、策略条件及少量期货因子接入同一工作台。优先适配第三方计算，归一维护期货时序、来源身份、研究口径及证据。后续以相同接口承接高级检验、受控实验和 AI 辅助研究。

## Capabilities

- 新增 `statistics-research-center`。产品入口覆盖统计总览、策略分析、交易分析、因子实验室、市场与信号研究、AI 研究助手。各期开放条件见[设计](design.md)。
- 上游沿用 Market、Quant Core、策略目录、回测、模拟及交易日志的原合同。正式回测委托 RQAlpha Plus 回测中心，研究产出由人工审阅。

## Impact

拟在现有 FastAPI / Vue 内增加研究模块，重计算使用按任务启动的隔离 Python 环境。仅在实施阶段引入研究自身的索引和文件。本变更交付架构、[行为规格](specs/statistics-research-center/spec.md)与[实施任务](tasks.md)。来源为[最新设计讨论](chatgpt-conversation://6b0a7024-0990-83ea-899a-2614e37f4152)。
