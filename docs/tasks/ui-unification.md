## 实施与口径

复用已有 ReturnCurveSvg、returnCurveLayout 和详情弹层，不新建图表引擎。
PerformancePanel 为收益展示唯一公共外壳；业务 adapter 保留各领域的原事实。
页面普通/理论、CLOSED ReferenceTrade、marked reference、模型账户分别展示，
没有对应事实的策略不制造曲线。新 `drawdown_kind` 只声明实际计算类型，不改变源公式数值。
旧结果缺少声明时显示限定的损失统计名称，不依据临时按钮状态推断。

新苏冰 `/api/v1/research/new-subing/runs/{run_id}/equity-curve` 读完整冻结结果，
校验 hash，最多2000个原始点；保留端点、极值、合约及显式中断边界，不插值。
必保边界超过预算时显式失败，摘要保持冻结值；明细追加分页不进入曲线统计。

`/api/market/messages` 合并已保存 Newow 和 AlertEvent 投影，默认50条；
按发生时间/source/ID稳定排序，游标绑定查询、快照、来源版本及结果摘要。
Newow93天/500条、Alert366天/5000条上限不扩大；非READY流、截断及来源失败明确标为覆盖不足。
改变修订/来源结果时409要求刷新，不能混合新旧分页。消息发送尝试不等于送达。
