# WorkBuddy Visual Requirements Prompt

Use this prompt before visual or UI acceptance work.

Read the linked Issue, TASK, PR, screenshots, and relevant page requirements. Do not modify code.

Output:

- target page / route
- viewport and browser
- expected visual behavior
- states to inspect
- blocking criteria
- non-blocking criteria
- data or API preconditions
- screenshots needed
- next fixed command, if any

Use `PASS`, `FAIL`, or `NOT_VERIFIED`. Separate blocking and non-blocking findings.
