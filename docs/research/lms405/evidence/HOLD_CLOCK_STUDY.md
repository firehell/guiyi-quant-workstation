# 锁仓期间的计划期限

2026-11-25。延后锁仓期间的固定期限，能解释为什么部分锁仓会等到原方向恢复，影响集中在烧碱和PTA。两种计时在烧碱的恢复时间和下次清仓时间完全相同，清仓原因不同。现有证据不足以确定作者的计时方法，暂不选定默认变体。 [固定前像研究](LOCKED_EXIT_AUDIT.md)

## 计时与确认

冻结基线从计划建立起数12根已完成5分钟Bar。比较两个独立版本，以实际确认的研究状态决定哪些Bar属于锁定区间。确认锁定发生在触发Bar可读之后，该Bar计入方向敞口。确认恢复同样发生在触发Bar可读之后，该Bar仍属于锁定区间。

|版本|锁仓时|恢复后|
|---|---|---|
|`lms-near405-hold-clock-defer-v1`|继续计数，暂缓生成期限清仓建议|若已达期限，下一根已完成Bar重新适用到期规则|
|`lms-near405-hold-clock-pause-v1`|确认锁定期间的Bar不记入期限|从未用完的期限继续计数|

价格风险、环境失效、盘整目标、5分钟原方向形态和显式确认按原候选逻辑处理。风险与期限同根触发时，风险优先。已提出而未确认的锁定不产生停表。锁定区间只作用于当前持仓周期，清仓后按基线的固定窗口判断是否允许同计划回补。休市空档没有Bar，也就没有新增计数。报告中的模拟动作来自显式 `TEST_FIXTURE` 确认。 [原候选说明](../NEAR405_V1.md)

10月三个版本均有41次首次进入、5次锁定、40次清仓。两个期限变体各多一次SH恢复，事件从86变为87。11月三个版本均有13次首次进入、1次锁定、1次恢复、12次清仓。10月SH的新路径只有一根Bar的恢复时间，暂缓到期和停表对之后的敞口没有可观察差别。TA仍由环境关断。研究照录所有路径，两个窗口均未出现回补。作者的订单、成交与收益字段为空。

铁矿10月27日的两份同屏报价相隔18根5分钟Bar，均出现开均一致的多空各16。若账户连续、期间保护腿未重开，两种变体均可在其他退出条件未触发时容纳这段锁定。作者实际锁入时点、期间的动作和恢复后继续持仓的时间仍不明。判断两种计时需要一条带盘前有效期限、连续前后持仓和恢复后数根Bar的作者时间链。 [铁矿案例](I2701_OCT_CASE.md)
