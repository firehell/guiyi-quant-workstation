# Workstation Legacy TASK Archive

本目录保存 WorkBuddy Unified V3 之前的工作站旧 TASK、Demo TASK 和验收记录。

这些文件只供历史追溯：

- 不作为当前 active TASK；
- 不作为 dispatcher 当前执行契约；
- 不代表 WorkBuddy V3 当前命令或审批规则；
- 不恢复 CodeBuddy daemon / Lean V1 / V1.1-V1.5 旧流程为 active 事实源。

当前 TASK 应放在 `docs/tasks/<TASK_ID>.md`，并通过 GitHub Issue / TASK / Draft PR / `.ai/results/<TASK_ID>/` 五层事实模型执行。
