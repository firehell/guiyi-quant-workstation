# 苏冰阶段二：退出事实与联合案例核对

用户已认可2.4上涨背景回踩页面效果，继续补齐阶段二尚缺的退出事实及联合核对。
本轮不实现阶段三的持仓、执行、费用、风险、冷却或日终状态机，不生成交易、收益或正式信号。

联合口径 `subing_joint_conditions_v1`：

- 当时最后一根已完成、同物理合约的日线方向UP或NEUTRAL允许继续；DOWN禁止，缺失或UNKNOWN不可判定。
- 同一根已完成30m须同时满足：方向UP（>5°）、close>EMA21、新金叉交点h∈[-4,4]、volume>前根。
- 不沿用过去金叉，不等待后根补齐条件。日线与30m同一结束时间时，使用更早日线（strict-before）。
- 任一资料未知，整体met=null，并分别列出missing和failed；只有全部已知且为真才met=true。
- 日线量能、30m放量档位、回踩均不增加首仓门槛；无加权评分。
- met=true仅表示首仓技术条件齐全，空仓/等待期/资金/日终/风控/成交资格尚未检查。

退出事实：

- close<同物理合约前根low，输出普通减仓依据；严格小于，等于不触发。
- 共享MACD的本根高位死叉h>17，输出另一普通减仓依据。
- close<EMA21，输出技术清仓依据；等于不触发。这与回踩资格close<=EMA21失效有意不同。
- 同根可同时出现，多根可重复。没有仓位也照实展示，不推定实际减几手或发生清仓。
- 前根low从完整物理前缀读取，可早于可见窗口；不跨合约拼接。原始Decimal比较，不经浮点展示值回算。

页面逐根展示五项首仓条件、日线来源时刻、前根低点及来源、三项退出事实和回踩管理依据。
“前/后首仓成立”仅为事后导航，不向当前结果输入未来资料。

导出：`scripts/research/subing_trend.py --joint`，自动包含四个已有因子，延用只读MDS入口、质量验证和源hash。
测试：`tests/unit/subing_conditions`、`tests/unit/subing_trend/test_export.py` 及原因子回归。
