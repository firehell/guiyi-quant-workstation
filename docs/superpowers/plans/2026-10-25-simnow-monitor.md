# 首页模拟交易监控与复盘

Owner已批准方案：市场/消息/模拟交易共用导航；只读概览、原生权益曲线、持仓/执行记录/待核及信号→风控→订单→成交抽屉；可见时5秒刷新，隐藏或离开暂停，翻页/明细不被刷新打断。第一版不增加逐笔胜率/开平配对收益和交易按钮。

1. 建立单一显式监控根及原子索引，绑定账户指纹和来源；受控宿主发布开始/查询进度/结束状态。监控失败不能改变交易流程。
2. SQLite只读投影：检验账户/来源/hash/schema，复用Decimal与现有费用/绩效/冻结去重逻辑；新增概览、分页记录及执行链API。未接入/异常/未知不当空仓或零收益。
3. 导航、Tab记忆、类型化客户端和可中止的5秒刷新。筛选/翻页/抽屉期间保留旧列表，仅提示新记录，迟到响应不得覆盖。
4. 沿用首页白底橙色、紧凑表格、筛选/状态组件；原生权益及可证明净收益断线图；移动端全屏明细。
5. 后端RO/源损坏/并发/跨日待核回归，前端刷新/切换/分页与未知展示测试，桌面/移动浏览器视觉验收，独立高风险Review，commit/push/集成develop。仅开发页面，不发布/切Runtime/启用持续交易。

实施约定：宿主监控根固定为PROJECT_ROOT/output/simnow-controlled；API以GUIYI_SIMNOW_MONITOR_ROOT显式选取该同一根（默认API的PROJECT_ROOT/output/simnow-controlled），跨工作区预览时配置为宿主根，不改变宿主已有私有输出目录；monitor.json只为运行索引，不是经济事实。只接受一个绑定账户，不glob或选择mtime最新目录。账户、发送和原生证据库均mode=ro；各自来源时间可不同，标明来源/完整性，不宣称跨库原子快照。
