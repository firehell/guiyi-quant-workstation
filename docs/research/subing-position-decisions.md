# 焦煤苏冰3.2：持仓决策与离线动作回放

本轮实现独立离线决策内核 `subing_jm30_decision_v6`。处理JM多空镜像、同一时刻只持一个方向、固定30m技术条件与完成1m检查，首仓1手、每次加1手、最多3手。
不创建Broker订单，不接正式Runtime，不计算历史收益；完整执行、费用及账户事实适配见[3.3历史账户回放](subing-account-replay.md)。

## 输入与职责

`DecisionModel(contract, run_id).apply(event)`接受显式观察或确认事件，返回before、facts、actions、after。
`checkpoint()`保存带版本及校验和的事件日志，`restore()`通过重放恢复；重复event_id及相同内容幂等，身份冲突、乱序和跨合约输入拒绝且不污染状态。

观察输入必须由调用方保证来自连续completed行情及权威Session；内核不代替MDS验证coverage。
每日方向必须携带严格早于观察时刻的来源时间。30m事实来自[阶段二联合条件](subing-joint-conditions.md)与[回踩因子](subing-price-factor.md)，没有第二套指标计算。
首仓复用交叉当根及后续五根完成30m窗口；只在空仓、无未决动作、无日停开及显式准入通过时申请1手。多头日线UP或NEUTRAL、分钟角度>0且零轴附近金叉；空头日线DOWN或NEUTRAL、分钟角度<0且零轴附近死叉。成交量条件相同，各方向维护独立交叉窗口。

交易资格与阶段二展示资格分离：加仓使用持仓后新确认回踩的高点，严格后续完成1m收盘突破；不消费30m high的展示突破标记。
新增回踩可替换旧回踩；减仓及清仓清除交易资格，成交后重新等待新回踩。未知/失效回踩不能放行。

`admission`、`round_loss`、`day_loss`、`remaining_net`和`reconciled`由外部显式提供。
这些不是内核生成的资金证明：3.3负责10万元起始账户、2000元整轮净亏、5000元交易日净亏、70%权益保证金上限及费用计算。
缺少准入或风险事实时拒绝新增仓位，已经可知的退出条件仍处理；日终净浮盈未知不伪造为盈利。
日终区间由Session适配者确定为日盘14:50至结束，不用自然日推算夜盘交易日。

## 动作合同

1. 清仓优先于减仓，减仓优先于加仓。同一时点发生退出不加回。
2. 成交之后严格更晚的完成1m收盘低于加仓层实际确认价，退出该层；不受保留一手限制。
3. 30m收盘跌破前根low、高位死叉h>17各减1手；先排除保护退出层，再从剩余仓位最近层减，普通减仓保留至少1手。
4. 收盘破EMA、整轮亏损、日亏或日终非正净浮盈形成清仓义务；原因并列、仓位不重复退出。
5. 日线不允许当前方向或UNKNOWN、日终区间、日停开、对账未通过及风险未知均禁止新增。已挂起开仓失去资格时发出取消请求，等明确确认后才解除未决状态。
6. 只有显式成交确认才更新逐手仓位。部分平仓确认只移除指定层；取消不算成交。确认必须晚于决策时刻。
7. 已取消清仓后10根30m冷却。完全清仓后清空两个方向的旧交叉机会；严格后续观察出现新的有效交叉即可申请开仓。同一清仓确认时间不生成新OPEN，不自动反手；没有固定等待根数。
8. 交易日停开只允许下一交易日对账确认后解除，不清除尚未完成的退出义务。

价格、金额输入使用十进制字符串；确认输入仅是本回放的显式执行记录，不经此工具认证为Broker事实。未知成交不能通过取消或空账本伪造恢复。
清仓及减仓未决时仍保留原仓位；保护或清仓义务不会因取消某次平仓申请消失。

## 阶段四：固定初始止损、1R主动止盈与加仓复核

v4只改变本离线研究语义，不晋升Runtime。首仓信号采用实际发出OPEN的已完成30m（不是五根窗口最初金叉Bar）：初始止损为 `min(EMA21-13, low-13)`，13为价格点。止损须为正且低于信号价；成交前若实际模型价不高于止损则取消。首仓确认后固定 `R=成交价-止损` 和 `目标价=成交价+R`，加减仓不重算。完成1m收盘≤固定止损产生全清义务，按严格后续分钟执行，不保证止损价成交；原EMA、整轮、日亏及日终退出继续生效。

从首仓成交后统计完成30m，第3根完成时点及以前第一次达到目标算快涨，此后算慢涨（休市不增加Bar数）。快涨选择全部扣费后净盈利的加仓层，最多退出2手；慢涨只选择最近一层净盈利的加仓层。始终保留OPEN底仓。首次达到目标即消耗该轮1R机会，包括当时仅有底仓或没有已证明盈利加仓层；允许以后新回踩加仓，但不重复该轮1R止盈。净盈利是当前已完成价浮盈减该层开费及预计平费，不保证下一分钟实际成交仍盈利。

新增观察财务输入 `base_net`、`layer_nets` 由账户计算，未知不放行加仓或利润减仓；30m增加 `ema21`、`low`。ADD请求及成交前底仓净浮盈必须严格>0；成交前完成1m收盘必须仍严格高于请求冻结的回踩高点。失败取消并消耗该机会，不因价格恢复重播，必须等待新的回踩和突破。首次1R命中也阻止同一分钟新增仓位。

全清优先，其次加仓保护及普通减仓；1R目标与已有退出层取并集、同层不重复退出。退出义务持久保留至成交；目标扩展时用新身份和当前时点替换未决CLOSE，已成交层不重复处理。普通减仓仍各条件减1手并保底仓。检查点记录固定止损、R、目标、完成30m计数、快涨截止时点、1R已触发状态及待退出层，按新语义重放恢复；旧版本不冒充新版本。


## 阶段四：取消冷却与镜像做空（v5）

2026-11-01 owner授权去掉冷却、加入做空镜像。讨论后的最终范围不增加尾盘提前开仓：14:50至日盘结束仍禁止新增，原有日终非正净浮盈退出保留。尾盘14:55入口未启用。

| 规则 | 多头 | 空头 |
| --- | --- | --- |
| 日线方向 | UP / NEUTRAL | DOWN / NEUTRAL |
| 入场 | 角度>0、收盘>EMA、[-4,4]金叉窗口、当根有效量 | 角度<0、收盘<EMA、[-4,4]死叉窗口、当根有效量 |
| 初始止损 | min(信号EMA, 信号low)−13 | max(信号EMA, 信号high)+13 |
| 固定R与首次目标 | R=首仓成交−止损；目标=成交+R | R=止损−首仓成交；目标=成交−R |
| 固定止损触发 | 完成1m收盘≤止损 | 完成1m收盘≥止损 |
| 新增加仓 | 持仓后有效回踩，后续1m收盘>回踩高点 | 持仓后有效反弹，后续1m收盘<反弹低点 |
| 加仓保护 | 成交后更晚1m收盘<该层成交价 | 成交后更晚1m收盘>该层成交价 |
| 普通减仓 | 收盘<前根low、高位死叉h>17，各减1手 | 收盘>前根high、低位金叉h<−17，各减1手 |
| EMA清仓 | 30m收盘<EMA | 30m收盘>EMA |

两方向复用同一持仓状态机与账户，不维护同时持有的多空子账户。底仓1手、每次加1手、总计最多3手；加仓仍须底仓扣费后净盈利，执行前再次核对。快速达到1R减最多2个盈利加仓层，慢速只减最近1个；首次触发消耗、保留底仓、之后可重新加仓但不重复该轮1R止盈，均完全镜像。

实际方向写入意图、逐层仓位和账户成交；`breakout_level`记录多头回踩高点或空头反弹低点。空头止损引用实际OPEN信号30m，不使用交叉窗口源K替代。旧v4检查点不作为v5恢复；旧历史结果保持原身份。整轮−2000、交易日−5000、最大70%保证金、未决退出义务和严格后续成交不变。


## 第一档首仓达到1R全清（v6）

2026-11-01 owner确认镜像空头、取消冷却及原尾盘退出案例均符合，并新增：**实际发出首仓OPEN信号的已完成30m成交量档位为TIER_1时，首次达到固定1R目标清掉全部仓位，包括底仓**。同轮不分快慢，不受“只退出盈利加仓层”的限制，多空镜像。

档位沿用独立因子：TIER_1为1<本根量/前根量<2；TIER_2为2≤比值<3；TIER_3为比值≥3。档位来源是实际OPEN信号K，不是金死叉窗口的源K、不使用后续模型成交K或达到1R时的K。`m30.volume_tier`先冻结在OPEN意图的`entry_volume_tier`，首仓成交后进入本轮状态；后续行情档位及加减仓不改变它，完全清仓后重置。

TIER_2、TIER_3仍按v5规则：快涨/快跌选全部盈利加仓层最多2手，慢涨/慢跌只选最近1层；保留底仓、首次达标消耗、后续不重复。R和目标仍由固定初始止损与首仓实际模型成交价计算，不因量档变化。

首档触发使用`PROFIT_1R_TIER1_CLEAR`持久全清义务，和已知风控原因并列；扩展已有减仓目标，取消未成交ADD，晚到加仓确认仍纳入后续全清。部分成交、未成交重试与检查点恢复不丢失退出义务。执行仍在严格后续可执行1m，不保证以1R目标价成交，也不保证每个加仓层盈利。

UNKNOWN、ZERO_BASELINE（前根零量）、NOT_EXPANDED不能证明三档首仓政策，OPEN拒绝并记录`ENTRY_VOLUME_TIER_NOT_PROVEN`；不把零基数伪归第一档或第三档。原量能因子定义不变。v5检查点保留旧身份，不用v6恢复冒充历史。
