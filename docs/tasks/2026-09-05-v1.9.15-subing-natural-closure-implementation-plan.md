# v1.9.15 Release 与 SuBing 自然推送闭环 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将执行时最新、已收敛的 full `develop` 全量冻结为 `v1.9.15` Release Candidate，完成 exact-head 全量验证和双轴 Review，随后在独立人工 Gate 下完成 release、PF2611 physical-contract warm-up、五项 Runtime promotion，并等待自然 SuBing 15m Event、PushPlus provider acceptance 与 Owner 微信实际送达确认。

**Tech Stack:** Git/GitHub PR + annotated tag + GitHub Release、Python 3.13、FastAPI、SQLAlchemy/PostgreSQL、RQData、Canonical Parquet、Redis/launchd、Vue 3/TypeScript、pytest、Ruff、Mypy、Node test、Playwright、OpenSpec、PushPlus。
