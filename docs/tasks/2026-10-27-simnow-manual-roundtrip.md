# 人工模拟验收与关闭恢复实现

本任务增加独立于策略信号的人工验收入口，复用既有账户、发送及原生证据账本，不初始化或清除已有事实。
账户明细及现场结果保存在本机私有输出，不纳入本交付说明。

## 实现

- ManualBeginV1 / ManualTickV1 固定单品种、一手、一次OPEN，完整核验后持有600秒再允许关闭。
- Session准入检查当前连续交易段，不能用最终收盘时间忽略午休或短休；保留报价新鲜度及账户资金检查。
- 首笔资金查询可显式使用一次45秒宽限，其余及后续快照仍15秒；默认观察入口不变。
- 开仓前恢复绑定既有失败事实、诊断及预算、三份数据库前像和短期计划；不换身份清零重试。
- 已认领订单的关闭恢复使用独立管理预算，Host/Adapter两层禁止OPEN或反手。
- CorrelatedNativeFillV1 保留原生与本地时间，凭完整快照hash、请求身份、系统号、实际费用及Session证明建立因果。
- 未解释成交持久待核；已知中间订单可由同身份终态覆盖，未知身份立即阻断。旧NativeFill及历史重放语义不变。
- 最终检查委托/成交、费用、权益、预留、未决回调与原生释放；不会以本地计时或请求返回码宣称成功。

## 验证及边界

扩大回归454项通过；独立409项及隔离SDK25项通过，Ruff、secret扫描及diff检查通过。
真实LocalStore/Host/Adapter离线回环覆盖未知提交、原生时钟偏差、完整核验后600秒、平今、费用/权益和旧回执重放。
原始现场记录只保存在本机；准时平仓、策略自然信号、反手、换月、断线/跨日与全品种持续执行分别验收。
代码集成以[PR518](https://github.com/firehell/guiyi-quant-workstation/pull/518)实际状态为准；本任务不发布或切换正式十服务。
独立服务入口保持observe-only，自动开仓关闭。实现完成不能替代新的自然业务证据。
