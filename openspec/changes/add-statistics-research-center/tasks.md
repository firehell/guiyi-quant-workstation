## 1. V0.1 隔离接入验证

- [x] 1.1 在 Apple Silicon / Python 3.13 单独锁定依赖，验证 QuantStats 显式参数、VeighNa Alpha 4.5.0 外部特征与标签接口；记录可用算子与不能采用的默认行为。
- [x] 1.2 选一个已有合格物理合约 Run，对照已核验日收益、手算与 Plus 同口径指标，覆盖累计/月度收益、回撤与持续期、年化和风险调整指标，先定误差阈值，逐项解释差异。验证缺日、净入金、零分母与未平仓。
- [x] 1.3 在不影响现有服务的隔离环境，以固定候选品种清单及窗口实测资源与结果复现。记录 57 品种基线、预算、峰值资源、延迟和失败成员。

V0.1 验收使用物理合约 FU2603 的已发布 Plus Run、只读 Canonical 5m、独立 PostgreSQL 与锁定 worker。工作台可按月定位日结、按方向与时段定位交易、回查原 Run 或案例。账户或市场状态证据缺失时返回缺项。盘中与运行中服务的并行负载留待对应应用部署验收。

隔离验证命令与样本证据见[研究环境复验](../../../services/research-worker/README.md)。
