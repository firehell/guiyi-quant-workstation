## 1. 目标、批准范围与事实优先级

### 1.1 本轮目标

在既有归一 Market 产品内，提供本地优先、单用户、面向国内期货的桌面研究工作站。沿用用户批准的牛哇参考视觉方向，让品种选择、策略阅读、主副图观察、参考交易定位形成连续操作体验；不增加账户、订单、实际持仓或无人值守交易能力。[S1][S2]

用户确认的方向是：无左侧常驻功能切换栏、横向充分利用窗口、深色画布、橙色选中态、低遮挡图表、半透明层次、中文优先（周期保留原始频率键）、约 60 个期货品种的轻量选择方式，以及牛哇、火天大有、苏冰预警的明确入口。[U1]

发生冲突时：现行业务 canonical 优先；用户明确的本轮范围约束约束设计；批准图片约束视觉方向。图片不授权新增策略、周期、订单、数据计算或生产操作。真正改变业务合同须另立任务，不能夹带在本轮 UI 改造内。[S1][S2][S3]

不新增研究笔记、回测复盘产品、AI 助手、账户/成员管理、股票全市场搜索、订阅付费或社交能力。现有“参考交易”和“综合解释”不是这些未来模块，不能因精简导航而删掉。只新增桌面交互设计与展示适配；不为手机新建一套设计，也不借机删除既有兼容行为或测试。[U1][S1]

## 3. 页面与能力矩阵

### 3.1 导航结构（NUX-01）

顶部提供“市场”“牛哇”“火天大有”“苏冰预警”。市场对应 `/market`，其余是 `/market/chart` 的分析视角，不新增四套业务应用或路由。

“自由看盘”是当前已有能力，应保留在明确可发现的分析视角菜单中，不因效果图未画出就删除。牛哇视角内才显示“趋势 / 震荡 / 主升浪”三个策略切换按钮。火天大有和苏冰切换后不继续显示牛哇参考收益或主动作状态。[S1][S6]

| 视角 | 周期能力 | 图层与记录 | 本轮处理 |
|---|---|---|---|
| 牛哇 | `1w / 1d / 60m` | 自身主动作、Hint、ReferenceTrade、综合解释与支持的辅助指标 | 公共 Shell 与核心交互重点 |
| 火天大有 | 七个正式周期：`1m / 5m / 15m / 30m / 60m / 1d / 1w` | 区分 Web 历史重绘观察与持久 first-seen Event | 复用外观，不改 kernel、Scope、Event |
| 苏冰预警 | 固定 `15m` | Event-backed 标记与预警详情 | 复用外观，不从 MACD 图直接生成 Event |
| 自由看盘 | 使用当前合法的通用图表能力集合 | 已有通用指标和合约控制 | 保留，不在此扩展 |

能力支持不等于 Runtime 已授权运行。特别是火天大有七周期展示能力，不能推断所有品种七周期都已启用通知。[S2][S4]

### 3.2 品种选择（NUX-02）

主入口是“全部品种”紧凑选择面板；按照已有交易所或板块元数据分组，显示中文名与品种代码。顶部横条可展示一组快捷品种，溢出使用横向滚动或“全部品种”，不铺满 60 个按钮，不新增全市场搜索或自选股产品。

当前设计按 60 个 operational 品种校准密度，但数量和成员必须来自既有权威集合，不能在前端硬编码 60 或合并 active 与 operational 授权。未拿到集合时显示加载/不可用，不用演示名单冒充真实集合。[S1][S2][S4]

点击只改变浏览上下文，不改 Scope、不订阅新的 Runtime 品种、不触发通知。选择面板支持 Tab/方向键浏览、Enter 确认、Esc 关闭；关闭后焦点回到触发入口。键盘规则属于已确认的归一适配，不宣称已观察到牛哇完全相同的行为。

## 4. 上下文切换与状态保持

### 4.1 身份原则（NUX-03）

页面上下文至少包含视角、品种、策略（适用时）、周期、序列类型、物理 owner/segment、输入版本与快照身份。具体字段名继续服从既有 typed API，不在此另造后端协议。

切换身份时先撤销旧选择和旧解释的当前有效性，再加载新上下文。晚到响应不能覆盖已经切换到的新页面。保留骨架或注明“旧快照”的只读内容，与把旧内容冒充新身份是两回事。

### 4.2 状态保持表

| 用户操作 | 应保留 | 必须清除/重核对 |
|---|---|---|
| 切品种 | 当前视角、该视角合法周期及已批准的纯显示偏好 | 旧物理合约、旧 Action/Hint/Event 选择、旧 tooltip、旧解释、引用身份 |
| 牛哇切策略 | 品种、合法周期、公共外观；仅在同输入窗口兼容时保留时间范围 | 旧策略主动作、Hint、参考交易绑定；不可携带旧策略收益 |
| 切周期 | 品种、视角、合法策略、显示偏好 | 旧周期坐标、选中标记、旧指标值；按新周期重建，不前端合成 |
| 切分析视角 | 品种；目标视角已经支持的恢复信息 | 其他视角的图层、动作、参考交易和 Event 语义 |
| 切副图 | 主图上下文、可见时间范围、已选 Action | 上一个副图的浮层和值；核对新副图返回身份 |
| 主图加载更早历史 | 显式统计窗口；服务端证明兼容时保留参考交易 | 不相容的 snapshot/version/owner 绑定必须失效 |
| 仅缩放或平移 | 策略、计算结果、参考交易窗口与身份 | 只更新屏幕可见范围，不改变统计口径 |
| 浏览器刷新/后退/前进 | 合法 URL 上下文及已有合法偏好 | 临时 hover、不可靠缓存和不适用的历史选择 |

状态保持原则已确认；精确生命周期与跨策略范围兼容判断由 Engineering Spec 对照既有 route/loader 收敛。当前代码切视角/品种/策略/周期会清空选择、副图和研究 tab；本轮不能声称“默认 MACD”已经存在。[S5][S6]

非法 URL 周期或策略必须有明确不可用/规范化说明，不能以静默换数据的方式伪装成功。进入苏冰时显式显示“15m（固定）”。

## 5. 主图、成交量与副图

### 5.1 主图（NUX-04）

保留批准的黄蓝趋势层、紧凑价格轴、清晰 K 线与低遮挡标记。所有几何形状绑定现有 series/state，不新增算法。趋势页不以 MA20/MA60 替代现有 page-v2 A/B，也不因图像中出现某根线就推导新指标。[S3]

物理合约或 segment 变化时，应呈现边界，不跨界填充趋势带或连接 Hint/参考交易。价格显示保留合约所需精度；不得为了复制截图截断有效 tick。Hint 的显示锚点不是成交价格，不能靠格式化伪装成可执行报价。

### 5.2 成交量（NUX-05）

成交量位于主图下方的紧凑独立区域，读取同一品种、物理区段、周期与时间键的权威字段。持仓量是独立字段，不能用成交量替代；前一可比较值不足时，日增仓显示不可用，不在换月处擅自跨合约相减。

成交量缺失不自动画成零。若当前 typed 产品响应不提供同身份字段，应先核对可复用 authority/接口接入；这是工程前置项，不是授权前端重算数据。

### 5.3 副图选项与默认值（NUX-06）

按照已批准图片的单副图区形式，V1.1 已确认：默认显示 MACD；同一区域可切换“MACD / 照妖镜 / 涨跌动能 / 主力控盘”。一次展示一个指标，成交量不占此选择位。点击已选副图保持显示，不因重复点击突然清空。

这里明确选择“单区域切换”，不擅自扩大为多个副图同时堆叠。该规则是对静态图的交互补充，已由本轮用户确认。

MACD 是项目已有通用指标，但当前 NewowProductWorkspace 的 auxiliaryOptions 只有三项 Newow 指标，没有 MACD；同身份通用 MACD 的读出/接入方式由 Engineering Spec 核对并定义。不能把“算法已存在”写成“Newow 页面已接通”，也不能新增一套浏览器 MACD 计算。[S1][S5]

| 副图 | 必须保持的图形语义 | 不得做的事 |
|---|---|---|
| MACD | 零轴、正负柱、DIF/DEA、参数与权威读值；精确柱口径沿用现有 authority | 不能把生成图中的数值或缩放比例当参数；不由视觉 CROSS 生成苏冰 Event |
| 照妖镜 | 已证据支持的零轴及分类彩柱；常驻“历史回看 · 会重绘” | 不能简单把 MACD 改标题；不能当历史当时可知的正式信号 |
| 涨跌动能 | 按自身 typed 输出与证据确定 series、标记和图例 | 不能用通用折线/随机柱状图假装完成 parity |
| 主力控盘 | 按自身输出表达数值与状态，保留解释身份 | “主力”名称不证明真实席位或持仓 |

未取得原站某副图的真实启用态，仍可设计归一适配草案，但不能标为原站精确复刻。照妖镜 `repainting=true / formal_signal_eligible=false` 不因其出现在主图下方而改变。[S1][S3][A1]

### 5.4 主副图联动（NUX-07）

同一时间位置的 K 线、成交量和当前副图共享时间阅读位置。价格轴与指标轴独立；同步的是时间，不是把三种数值放在同一纵轴。

hover 显示时间、对应物理合约、OHLC、成交量、持仓量以及当前副图可用值。普通行情读值使用同一 Bar；缺值显示“—”与原因，不取邻近日期补值。照妖镜的回看值另标当前计算 as-of，不能宣称为该历史 Bar 当时已知。

tooltip 靠近观察位置且避开关键标记，越界时换侧；鼠标离开图表后消失。十字线消失不取消用户已经明确选中的 Action。最新行情摘要不被历史 hover 静默改写，历史字段应位于明确的“所选 K 线”读值区。

上述联动行为是归一目标交互。Stage 1 没有取得足够的真实牛哇 hover/联动录像，本稿不据此关闭 E03。[A1]

## 6. 标记、中文标签与说明层

### 6.1 分类（NUX-08）

主动作、Hint、HTDY 历史图层、持久 AlertEvent 必须具有可区分的图形和说明身份。颜色之外，应有文字或形状区分。橙色主要用于界面选择反馈，不能把所有策略/预警结果强制染成橙色。

主动作点击可进入对应参考事实；Hint 点击/聚焦只展示来源、条件解释和限定，不产生交易或仓位动作。图例显隐只改变绘制，不改变策略结果、统计或请求 Scope。图例可点击性是已确认的归一交互，不是已验证牛哇行为。

D1–D6 的中文是用户确认的显示别名，不是宣称牛哇官方命名。主界面可压缩为“风险·一型”“观察·四型”，但详情必须显示原始编号与实际含义。D4–D6 不出现在不适用的趋势页上；普通周期选择器也不得出现“D4”。所有周期按钮、表格、摘要、tooltip 与来源周期统一显示原始键；仅可在说明层追加中文释义，不替换键。横轴日期与时间格式不受该显示选择影响。[S1][S3]

### 6.3 密集标记

标记拥挤时允许合理错位、引导线与选中提升，但不得把多个不同身份的动作合成一个业务信号，或将重要风险完全隐藏。详细碰撞阈值与图形尺寸留给工程设计和固定数据截图校准；不能从生成图估算后宣称是原站精确参数。

## 8. 加载、失败、不可用与运行状态

### 8.1 请求状态（NUX-13）

| 状态 | 用户看到的反馈 | 必须避免 |
|---|---|---|
| 尚未请求 | “尚未加载”与明确读取入口（适用于按需区域） | 误标为无数据 |
| 加载中 | 保持布局的骨架/局部加载提示 | 瞬间显示零值；同时显示旧身份结果 |
| 成功且有值 | 正常图形，必要 as-of/身份可查 | 把 fixture 称为实时数据 |
| 成功但没有主动作 | “当前窗口无主动作”，K 线及可用指标保留 | 误标策略不可用 |
| 成功且没有行情数据 | 当前品种/周期/区间无可用行情 | 用零价画图 |
| 预热不足 | “数据预热不足”，可读的独立数据继续显示 | 借其他合约/周期补值 |
| 证据不足 | “缺少核验证据”，保留对应 gap | 把未知显示成 0 分/无信号 |
| 当前组合不适用 | “当前组合不适用” | 无意义重试或静默换周期 |
| 读取失败 | 局部错误和只读重试入口 | 触发生产修复、补发或 Scope 变更 |
| 旧快照/身份冲突 | 明确过期或不兼容，禁用依赖该身份的定位 | 隐藏失败、继续把旧事实当当前 |

上述是展示状态，不新建业务 Event 状态机。

### 8.2 运行与推送区（NUX-14）

只展示既有只读 API/状态可支持的内容，并展示观察时间。当前或最后一次错误不能被“进程运行中”“HTTP 200”“aggregate ok”覆盖。

推送人数由外部 Topic 人工管理，系统不读取成员清单；用户本人加三位朋友是使用边界，不是系统核验的实际人数。界面不显示“四人已送达”“未读人数”或逐人状态。[S2]

“服务商已接受请求”与“用户人工确认收到”分开；未有后者不能写“微信已送达”。本页不增加测试推送、重发、启用/禁用、成员管理或错误 acknowledgment 控件。本轮页面设计不改变任何真实运行事实。[S2][S4]

### 9.2 桌面尺寸（NUX-15）

主校准视口拟定 1440 × 900 CSS px，另验收 1920 × 1080；DPR、浏览器、字体环境、缩放和数据集单独固定。原图的 1672 × 941 不直接作为 CSS 尺寸。

## 10. 牛哇原站证据与归一适配的界线

Stage 1 的证据结论继续保持 `READY_WITH_EVIDENCE_GAPS`。本轮只重新核对仓库与已生成设计图，没有采集新的牛哇在线交互录像、运行时 DOM 或真实行情浏览器结果。因此不能把本规格叫“牛哇全部效果与交互已覆盖并验证”。[A1]

| E04 Marker/Legend | 选择、显隐、Hint 限定已确认 | 原站点击/取消/重叠状态证据；或明确接受为归一适配 |
| E05 其他副图/MACD | MACD 是用户要求；接入已设计、未实现 | 各副图真实启用态与权威数据映射，不能以改标题代替 |
