# 归一量化系统功能点清单

> 项目定位：本地运行的国内期货量化研究、回测、复盘、信号扫描、模拟交易和后期半自动实盘辅助系统。  
> 第一阶段目标：先形成“数据 → 策略 → 回测 → 报告 → 复盘 → 信号”的研究闭环，不做无人值守全自动实盘。

---

## 1. 系统总定位

归一量化不是公开 SaaS，也不是普通行情网站，而是一个服务自用和少量朋友的本地期货量化工作台。

核心用途：

```text
数据下载
→ 数据清洗
→ 策略配置
→ 回测验证
→ 回测报告
→ 单笔复盘
→ 信号扫描
→ 模拟交易
→ 风控监控
→ 策略迭代
```

主要交易方向：

- 市场：国内期货
- 品种：黑色、化工、能源优先
- 风格：趋势 / 波段
- 周期：30 分钟、1 小时、2 小时、4 小时、日线优先
- 账户设计：按 10 万级别中小资金账户考虑
- 第一阶段：研究、回测、复盘、信号扫描、模拟
- 后期：天勤模拟 / 实盘接口、人工确认下单、风控拦截、半自动交易

## 6. 第一版暂不做功能

| 功能 | 不做原因 |
|---|---|
| 全自动实盘 | 第一版策略未充分验证，风险过高 |
| tick 级高频回测 | 与当前趋势 / 波段策略不匹配，工程量过大 |
| 复杂画线系统 | 容易把项目做成行情软件，偏离回测闭环 |
| Web 策略代码编辑器 | 第一版先用本地代码管理，避免安全和复杂度问题 |
| AI 自动写策略并直接运行 | 过拟合和安全风险高 |
| 多账户资金管理 | 个人 / 小团队阶段不需要 |
| 复杂组合保证金 | 中小资金趋势系统第一版不需要 |
| 云端部署 | 第一阶段本地 Mac / 工作站优先 |
| 多用户权限系统 | 自用系统暂不需要 |
| 手机 App | Web 本地工作台先跑通 |

## 7.8 回测中心

### 定位

回测中心是第一版核心，必须严谨。回测必须区分信号生成、成交撮合、手续费、滑点、保证金、风控和统计。

### V1 功能

- 单策略回测
- 单品种回测
- 多品种批量回测
- 多周期回测
- 参数配置
- 回测任务队列
- 回测进度推送
- 回测失败重试
- 回测结果归档
- 回测报告生成
- 交易明细生成
- K 线买卖点输出

### 回测引擎对象

```text
Strategy        策略逻辑
Signal          信号
Order           委托
Trade           成交
Position        持仓
Portfolio       账户
BrokerSimulator 撮合模拟
RiskManager     风控
BacktestEngine  回测引擎
ReportBuilder   报告生成
```

### 第一版撮合规则

- bar 级别事件驱动
- 当前 K 线收盘生成信号
- 下一根 K 线开盘或指定价格成交
- 固定滑点
- 固定手续费
- 按合约乘数计算盈亏
- 按保证金估算占用
- 不做 tick 队列撮合

### 必须防范

- 未来函数
- 数据泄露
- 当前 K 线信号当前 K 线成交导致结果虚高
- 忽略手续费
- 忽略滑点
- 忽略保证金
- 过度参数优化
- 只看收益不看回撤

# 14. 风控和真实性原则

任何策略、回测、信号和实盘模块都必须默认遵守：

- 避免未来函数
- 避免数据泄露
- 避免过拟合
- 回测结果不等于实盘结果
- 必须考虑手续费
- 必须考虑滑点
- 必须考虑保证金占用
- 必须统计最大回撤
- 必须统计连续亏损
- 实盘前必须先模拟
- 小资金验证后再扩大
- 第一版不做全自动实盘
