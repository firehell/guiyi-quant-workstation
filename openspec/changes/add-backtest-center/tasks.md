# 实施与验收

下列任务在后续实施时核验。本次设计提交不代表其中任一运行能力已交付。

## B1 · Plus 与牛哇趋势适配

- [ ] 在独立环境读回 Plus 版本、许可可用性、所需模块及现有数据覆盖，固定输入身份；验证 Market 离线可运行、缺执行分钟或缺授权时停止。
- [ ] 复用共享公式和 P1 手算样本，先验证趋势单合约的信号前缀、批量/逐步计算一致性、5m/1m 时序、撮合与 Decimal 逐笔/结算对账。对数据口径差异逐项归因。
- [ ] 标出试验与正式资格，验证缺 rank1 证明、换月、缺成本、未成交和期末持仓。其余目录项逐项显示资格与原因，保留旧 Run 可读。

## B2 · 配置、任务和 Run

- [ ] 实现模板与有效配置快照，记录可复算身份；验证模板修改、数据修订和不支持的参数均不会改写历史。
- [ ] 接通有界本机执行、进度、取消及显式重跑；验证重复提交、取消/完成竞争、进程重启、提交未知读回和乱序发布。
- [ ] 按 Run 原子发布研究结果并验证查询/分页只读，失败保留最近成功结果。

## B3 · 结果工作台

- [ ] 接入桌面工作台筛选、统计、近期策略/实验/验证和五个详情视图，逐项核对原生来源、成本口径与缺项展示。
- [ ] 从交易进入同一 Run 的 Quant Chart，验收部分成交、开仓未平、换月、数据修订不可重建和翻页期间有新结果等场景。

## B4 · 实验与验证

- [ ] 实现参数、策略、品种、周期及成本实验；核实可用的原生能力，必要时拆分成员 Run。用失败成员与不可比区间验证汇总。
- [ ] 固定训练/验证窗口和选参规则，验证 OOS 防泄漏、滚动折边界、预热排除、跨界未平仓和测试段价格扰动不改变已选参数、失败折标注与样本外汇总；报告可追溯到各 Run。
- [ ] 验证候选证据引用没有策略配置、运行或账户副作用。
