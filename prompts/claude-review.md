# Claude 代码评审提示模板

## 使用方式

提交代码评审时，将此模板与代码一起发送给 Claude。

---

## 评审请求模板

```
请对以下代码进行评审，重点关注：

【评审类型】（选择一个）
- [ ] 功能正确性
- [ ] 性能优化
- [ ] 安全漏洞
- [ ] 代码规范
- [ ] 量化逻辑

【代码文件】
[粘贴代码或文件路径]

【背景说明】
- 此代码的功能：[描述]
- 调用场景：[描述]
- 已知约束：[描述]

【期望输出】
1. 问题清单（按严重程度排序）
2. 改进建议（附代码示例）
3. 整体评级（通过/需修改/重写）
```

---

## 量化专项评审点

### 回测代码评审
```
检查以下回测代码中的常见问题：
1. 前视偏差（Look-ahead Bias）：是否使用了未来数据？
2. 存活者偏差：数据集是否完整？
3. 过拟合：参数是否过多？
4. 交易成本：是否计入手续费和滑点？
5. 资金曲线：复利还是单利计算？
```

### 风控代码评审
```
检查风控逻辑：
1. 是否所有下单路径都经过风控检查？
2. 极端行情下是否有保护机制？
3. 资金计算是否使用 Decimal？
4. 日志是否完整可追溯？
```

### API 代码评审
```
检查 FastAPI 路由：
1. 输入验证是否完整（Pydantic）？
2. 错误处理是否覆盖所有异常？
3. 是否有 SQL 注入风险？
4. 响应格式是否统一？
```
