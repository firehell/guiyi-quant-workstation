## ADDED Requirements

### Requirement: T01 盘中策略仅供已启用的独立模拟账户

系统 SHALL 按现有合同分别路由快期火天大有和苏冰独立量化的合格输入。名单来自显式模拟部署。新增参考策略默认走盘后。牛哇参考研究没有交易账户、报撤权或实时策略入口。

#### Scenario: 相同合约同时用于参考和模拟

- **WHEN** 给同一合约注入盘中新行情及其完成事件
- **THEN** 行情展示继续，快期仅向其火天大有宿主路由，苏冰仅向其 Paper 模型路由；牛哇参考消费者调用数为零。两个账户不共享资金、持仓、委托、成交或消费水位。

### Requirement: T02 独立账户遵循各自事实与恢复合同

系统 SHALL 保留快期火天大有 60m 的信号和既有报价、1m 准入、回报、对账路径；苏冰复用其已有 completed 输入与独立 Paper 账本。盘后 run 只产生研究结果。

#### Scenario: 盘后失败或离线重放

- **WHEN** 牛哇研究中断或重复，同时两个独立模拟宿主接收冻结的自然输入序列与各自适用的回报
- **THEN** 快期沿原生委托/成交身份处理，未知不重发；苏冰沿原 run 与序列恢复，模型成交不送柜台。同固定基线的决策、回报/模型事实可逐项核对。

### Requirement: T03 既有执行与退出义务受保护

系统 SHALL 保留快期撤余单、旧仓和平仓义务及苏冰各自约定的持仓、费用和换月处理。研究刷新不取得执行权或重置账户。

#### Scenario: 切读时仍有未决义务

- **GIVEN** 旧物理合约有仓、在途委托或未解释回报
- **WHEN** 更新研究版本、打开工作台或拟移除旧参考消费者
- **THEN** 保留相关账户输入与原始记录；缺少依赖证明时阻断相应退役，不自动发送、撤单或转移持仓。
