已知限制

1. Fallback YAML Parser — Inline List 解析

schema_validator._minimal_yaml_parse() 无法解析 inline list（如 depends_on: ["EXAMPLE-001"]），会将其视为字符串而非列表。YAML 模块不可用时，所有 V2 任务必须使用 缩进列表 格式：

depends_on:
  - "EXAMPLE-001"

2. Production Write Gate 关键词语义

任务体中包含 production / 生产 等关键词时，即使出现在无关上下文（如 YAML 的 production_write_approved 字段名），也会触发 Production Write Gate。这是设计行为（安全优先），但需要任务编写者意识到这一点。

3. Demo 测试生态约束

  • Stub 脚本 (stubs/) 替代 Codex CLI，输出固定 fixture
  • Dry-run 模式下的锁行为与实际执行可能有差异
  • __pycache__ 在无 PYTHONDONTWRITEBYTECODE=1 时会被标记为 dirty

4. 已存在的测试失败

3 个 pre-existing 测试失败源于 compat_reader / epic_manager 的 fallback YAML parser 限制，不影响 WS-V2 运行时行为（生产环境有 PyYAML）。
