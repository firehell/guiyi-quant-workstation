## 验证

基线：120 项定向 Node 测试通过（presentation、mirror primitive、chart stage、reference panel、loader）。各步骤的增量结果与最终验证在本文件更新。

首轮浏览器验证发现概览高度增加与旧夹具未覆盖 unified streams；收紧间距、按接口合同补空 streams 夹具后，3 项首屏/动作弹窗/失败重试用例通过。

照妖镜有意偏差：原站截图图例仍写蓝色拉高、黄色出货，但公开字段与绘图为 markup 黄色宽柱、distribution 蓝色窄柱。本次按字段与公式更正，非照抄错误图例。
