## 修复建议（需单独授权）
1. 云安全组开放 TCP 443；确认 Nginx 监听 443 且 certbot 证书有效
2. 云安全组限制或关闭 7000 公网入站；FRPS 仅允许 Mac mini 出口 IP 或内网
3. Nginx :80 配置 return 301 https://$host$request_uri（当前对 IP 访问返回 401）
