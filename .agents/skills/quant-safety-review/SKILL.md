# Quant Safety Review Skill

## 审查顺序

1. 数据时点：当前计算是否看到未来 K 线。
2. 信号时点：分型、N 字、突破是否提前确认。
3. 成交时点：当前信号是否错误地当前开盘/收盘成交。
4. 成本：手续费、滑点、合约乘数是否逐笔计入。
5. 风险：保证金、单笔风险、最大回撤、连续亏损是否统计。
6. 验证：样本内/样本外是否分离，参数是否过拟合。
7. 实盘：是否经过模拟和小资金验证，是否人工确认。

## 输出格式

- P0：必须立即修复。
- P1：本阶段建议修复。
- P2：后续优化。
- 测试建议。
- 是否建议继续/合并。

## 必查问题

- 是否使用未来高低点、未来收盘价、center rolling。
- 当前 bar 收盘信号是否当作当前 bar 成交。
- 是否只看收益，不看回撤、连亏、期望值。
- 是否把回测结果等同实盘结果。
- 是否存在未经风控的实盘下单路径。
